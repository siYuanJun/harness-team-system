# 角色交接协议

## 概述

定义 Hermes Agent Team 五角色之间的交接协议，确保信息传递准确、完整。

## 交接原则

1. **文件优先** — 重要信息通过文件传递，不依赖会话上下文
2. **结构化** — 使用标准模板，确保信息完整
3. **可追溯** — 记录交接历史，便于审计
4. **明确责任** — 交接双方确认，避免信息丢失

## 交接流程

### Coordinator → Researcher

**触发条件**：Coordinator 完成子任务拆解，需要研究支持

**交接内容**：
```markdown
## 研究任务包

### 任务 ID
{唯一标识}

### 研究目标
{需要研究的问题}

### 研究范围
- {范围1}
- {范围2}

### 期望输出
- 证据列表（含来源）
- 置信度标注（🟢🟡🔴）
- 关键发现摘要

### 截止时间
{时间}

### 特殊要求
- {要求1}
- {要求2}
```

**确认方式**：Researcher 收到任务包后，回复确认

### Researcher → Coordinator

**触发条件**：Researcher 完成研究任务

**交接内容**：
```markdown
## 研究报告

### 任务 ID
{唯一标识}

### 输出文件
- 研究报告: {路径}

### 摘要
{关键发现概述}

### 置信度分布
- 🟢 绿色: {数量}
- 🟡 黄色: {数量}
- 🔴 红色: {数量}

### 关键数据（仅🟢）
| 数据点 | 值 | 来源 |
|--------|-----|------|
| {数据1} | {值} | {来源} |

### 待确认事项（🟡）
- {事项1}

### 建议
- {后续建议}
```

**确认方式**：Coordinator 收到报告后，确认接收

### Coordinator → Writer

**触发条件**：Researcher 提供足够的 🟢 数据，可以开始写作

**交接内容**：
```markdown
## 写作任务包

### 任务 ID
{唯一标识}

### 输入文件
- 研究报告: {路径}

### 写作目标
{需要产出的内容}

### 期望输出
- 产出格式: {格式}
- 产出路径: {路径}

### 约束
- 仅使用 🟢 绿色数据
- 🟡 数据需标注"估计值"
- 🔴 数据不可使用

### 特殊要求
- {要求1}
- {要求2}
```

**确认方式**：Writer 收到任务包后，回复确认

### Writer → Coordinator

**触发条件**：Writer 完成写作任务

**交接内容**：
```markdown
## 写作产出

### 任务 ID
{唯一标识}

### 输出文件
- 产出草稿: {路径}

### 状态
- 完成 / 数据不足

### 数据使用情况
- 🟢 数据: {数量}
- 🟡 数据: {数量}（已标注）
- 🔴 数据: 0（未使用）

### 数据不足反馈（如有）
- 缺失数据: {列表}
- 影响: {说明}
- 建议: {建议}
```

**确认方式**：Coordinator 收到产出后，确认接收

### Coordinator → Editor

**触发条件**：Writer 完成写作，需要质量审计

**交接内容**：
```markdown
## 审计任务包

### 任务 ID
{唯一标识}

### 输入文件
- 产出草稿: {路径}
- 研究报告: {路径}（供参考，但 Editor 应独立验证）

### 审计范围
- 事实核查: 提取关键断言，独立验证
- 发布前检查: 按清单核对

### 期望输出
- 审计报告: {路径}
- 问题列表（如有）

### 特殊要求
- {要求1}
- {要求2}
```

**确认方式**：Editor 收到任务包后，回复确认

### Editor → Coordinator

**触发条件**：Editor 完成审计

**交接内容**：
```markdown
## 审计报告

### 任务 ID
{唯一标识}

### 输出文件
- 审计报告: {路径}

### 审计结论
- PASS / NEEDS_FIX / REJECT

### 事实核查统计
- ✅ 已确认: {数量}
- ⚠️ 待确认: {数量}
- ❌ 不一致: {数量}

### 发布前检查统计
- 通过: {数量}
- 未通过: {数量}

### 问题列表（如有）
| # | 问题 | 严重程度 | 建议 |
|---|------|---------|------|
| 1 | {问题} | 高/中/低 | {建议} |

### 后续建议
- {建议1}
```

**确认方式**：Coordinator 收到报告后，确认接收

### Coordinator → Human

**触发条件**：需要人类决策

**交接内容**：
```markdown
## 决策请求

### 决策节点
{节点名称}

### 背景
{决策背景}

### 选项
1. {选项1}: {说明}
2. {选项2}: {说明}
3. {选项3}: {说明}

### 建议
{Coordinator 的建议}

### 影响
{决策的影响}
```

**确认方式**：Human 做出决策

## 交接文件命名规范

```
_workspace/
├── 01_coordinator_tasks_{task-id}.md      # 任务拆解
├── 02_researcher_output_{task-id}.md      # 研究报告
├── 03_writer_draft_{task-id}.md           # 产出草稿
├── 04_editor_audit_{task-id}.md           # 审计报告
└── 05_human_decisions_{task-id}.md        # 人类决策
```

## 错误处理

### 交接失败

| 情况 | 处理 |
|------|------|
| 接收方未确认 | 发送方重发或通知 Coordinator |
| 文件丢失 | 重新生成或从备份恢复 |
| 信息不完整 | 补充完整后重新交接 |

### 数据不一致

| 情况 | 处理 |
|------|------|
| 研究报告与任务包不一致 | Coordinator 协调确认 |
| 产出与研究报告不一致 | Editor 审计发现，返回 Writer 修改 |
| 审计报告与产出无关 | Editor 重新审计 |

## 交接检查清单

交接前检查：

- [ ] 文件已生成
- [ ] 内容完整
- [ ] 格式正确
- [ ] 路径正确

交接后确认：

- [ ] 接收方已确认
- [ ] 文件可访问
- [ ] 内容无误
