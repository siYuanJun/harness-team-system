# 任务拆解指南

## 拆解原则

1. **MECE 原则** — 相互独立、完全穷尽
2. **可执行性** — 每个子任务可独立执行
3. **明确依赖** — 标注子任务间的依赖关系
4. **可验证** — 每个子任务有明确的完成标准

## 拆解步骤

```
1. 理解任务目标
   │
   ▼
2. 识别主要阶段
   │
   ▼
3. 分解为子任务
   │
   ▼
4. 确定依赖关系
   │
   ▼
5. 分配执行角色
```

## 路由决策

| 任务类型 | 路由 | 原因 |
|---------|------|------|
| 需要收集信息 | Researcher | 源头阻断，标注置信度 |
| 需要转化产出 | Writer | 使用🟢数据生成内容 |
| 需要验证事实 | Editor | 独立核查，不依赖 Researcher |
| 需要人类决策 | Human | 关键节点确认 |
| 简单整理 | Coordinator 直接处理 | 无需其他角色介入 |

## 常见任务模式

### 深度研究模式
```
Researcher(并行) → Writer → Editor
```

### 内容生产模式
```
Researcher(并行) → Writer → Editor → Human
```

### 快速回答模式
```
Coordinator → Writer（跳过 Researcher）
```

### 审计模式
```
Writer → Editor（跳过 Researcher）
```
