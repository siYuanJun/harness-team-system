# 绿色数据使用规范

## 核心原则

只有 🟢 绿色数据可以作为产出的核心依据。

## 数据分类使用规则

### 🟢 绿色数据（已核实）
**使用方式**：
- 可直接作为核心论据
- 可引用为事实
- 可用于决策支持

**标注方式**：
- 在引用处标注 🟢
- 在参考来源中列出完整 URL

**示例**：
```markdown
根据 Python 官方文档，Python 3.12 于 2023-10-02 发布 🟢。
来源: https://www.python.org/downloads/release/python-3120/
```

### 🟡 黄色数据（估计值）
**使用方式**：
- 可提及但必须标注"估计值"、"推测"
- 不可作为核心论据
- 需要说明局限性

**标注方式**：
- 在引用处标注 🟡
- 必须说明"估计值"或"推测"
- 说明推断依据

**示例**：
```markdown
该框架的用户量估计约 10 万+ 🟡（基于 GitHub stars 12k 推断）。
注意: 实际用户量可能更高，此数据仅供参考。
```

### 🔴 红色数据（推测）
**使用方式**：
- 禁止在正式产出中使用
- 如必须提及，需明确标注为"推测"、"无证据"
- 不可用于支持任何结论

**标注方式**：
- 在引用处标注 🔴
- 必须说明"推测"、"无证据"

**示例**：
```markdown
该团队可能使用 React 重写前端 🔴（推测，无直接证据）。
此信息未经验证，不可作为决策依据。
```

## 引用标注规范

### 文中引用
在引用数据处直接标注置信度：
```markdown
Python 3.12 于 2023-10-02 发布 🟢。
```

### 参考来源列表
在文档末尾列出所有引用来源：
```markdown
## 参考来源

### 🟢 已核实来源
1. [Python 3.12 Release](https://www.python.org/downloads/release/python-3120/)
   - 访问日期: 2026-08-13
   - 验证方式: 官方文档

### 🟡 估计值来源
1. [GitHub Stars](https://github.com/example/repo)
   - 访问日期: 2026-08-13
   - 推断依据: 基于 stars 数量推断用户量
```

## 数据不足处理

### 识别数据缺口
在写作过程中，识别以下情况：
- 关键论据缺少 🟢 数据支持
- 仅有 🟡 数据但需要更强证据
- 需要特定数据但未找到

### 反馈模板
```markdown
## 数据不足反馈

### 任务: {任务名称}

### 缺失数据
1. {数据点1}: 需要 🟢 级别证据
   - 当前状态: 仅有 🟡 数据
   - 影响: 无法作为核心论据
   
2. {数据点2}: 需要 🟢 级别证据
   - 当前状态: 无数据
   - 影响: 无法支持结论

### 建议研究方向
- {研究方向1}
- {研究方向2}

### 可选方案
1. 请 Researcher 补充研究
2. 调整任务范围，减少对该数据的依赖
3. 接受 🟡 数据并标注风险（需 Human 决策）
```

## 质量自检清单

在提交产出前，检查以下内容：

- [ ] 所有核心论据都有 🟢 数据支持
- [ ] 🟡 数据已标注"估计值"并说明局限性
- [ ] 🔴 数据未作为事实使用
- [ ] 所有引用都标注了来源
- [ ] 参考来源列表完整
- [ ] 置信度标注正确
