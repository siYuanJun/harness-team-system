# 事实核查协议

## 核查流程

```
1. 提取关键断言
   │
   ▼
2. 分类断言类型
   │
   ▼
3. 独立搜索验证
   │
   ▼
4. 交叉验证
   │
   ▼
5. 标注验证结果
```

## 断言提取

### 需要核查的断言类型

| 类型 | 示例 | 优先级 |
|------|------|--------|
| 事实性陈述 | "Python 3.12 于 2023-10-02 发布" | 高 |
| 数据引用 | "该框架有 10 万用户" | 高 |
| 因果关系 | "因为 X，所以 Y" | 中 |
| 技术细节 | "该 API 返回 JSON 格式" | 高 |
| 引用内容 | "某某说过..." | 中 |
| 最佳实践 | "推荐使用 X 方法" | 低 |

### 提取方法

1. **逐段阅读** — 识别所有事实性陈述
2. **标记数据** — 找出所有数字、日期、统计
3. **识别引用** — 找出所有引用他人观点的地方
4. **检查因果** — 找出所有因果关系陈述

## 独立搜索验证

### 搜索策略

1. **关键词提取** — 从断言中提取关键信息
2. **多源搜索** — 使用不同关键词搜索
3. **官方优先** — 优先查找官方文档
4. **交叉验证** — 至少 2 个独立来源

### 搜索技巧

| 断言类型 | 搜索方法 |
|---------|---------|
| 日期/时间 | 搜索官方公告、新闻稿 |
| 统计数据 | 查找原始报告、官方数据 |
| 技术细节 | 查阅官方文档、源码 |
| 引用内容 | 查找原始出处、视频/文章 |
| 因果关系 | 分析逻辑、查找佐证研究 |

### 来源记录

每个验证必须记录：
- 来源 URL
- 访问日期
- 来源可靠性等级
- 与断言的一致性

## 验证结果标注

### ✅ 已确认
**条件**：
- 至少 2 个独立来源确认
- 来源可靠性 ≥ B级
- 与断言完全一致

**示例**：
```markdown
断言: Python 3.12 于 2023-10-02 发布
验证: ✅ 已确认
来源:
- https://www.python.org/downloads/release/python-3120/
- https://docs.python.org/3/whatsnew/3.12.html
```

### ⚠️ 待确认
**条件**：
- 仅有 1 个来源
- 来源可靠性 C级
- 存在细微差异

**示例**：
```markdown
断言: 该框架用户量约 10 万
验证: ⚠️ 待确认
来源:
- GitHub stars 12k（推断）
说明: 仅有单一来源，实际数据可能不同
```

### ❌ 不一致
**条件**：
- 与事实不符
- 无法找到支持来源
- 来源可靠性 D/E级

**示例**：
```markdown
断言: Python 3.12 于 2023-09-01 发布
验证: ❌ 不一致
正确信息: 2023-10-02
来源:
- https://www.python.org/downloads/release/python-3120/
```

- 核查断言数量: {N}
