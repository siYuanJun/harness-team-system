# 圆桌辩论协议

## 基本原则

1. **对条目不对人** — 质疑必须指向具体条目编号和具体表述
2. **质疑必须有理由** — "我不同意"不是质疑，"我不同意，因为……"才是
3. **回应必须有结论** — 坚持 / 让步 / 部分接受，三选一，不许含糊
4. **两轮封顶** — 轮 1 交叉质疑，轮 2 收敛表态；仍分歧的转技术经理仲裁

## 轮 1 · 交叉质疑

每位 PM 对另外两位的产出逐条扫描，发起质疑需满足格式：

```markdown
### 质疑 {目标条目编号}
- 质疑方：PMx
- 被质疑条目：{原文摘要}
- 质疑理由：{为什么不同意，1-3 句}
- 要求：{希望对方补充什么 / 修改什么}
```

被质疑方回应格式：

```markdown
### 回应 {质疑指向}
- 立场：坚持 / 让步 / 部分接受
- 理由：{1-3 句}
- （若让步/部分接受）修订后的结论：{新结论}
```

## 轮 2 · 收敛表态

每位 PM 对**全部核心条目**（含自己提出的）输出最终立场表：

```markdown
| 条目编号 | 条目摘要 | 我的最终立场 | 一句话理由 |
|---|---|---|---|
```

立场只有三种：
- **同意** — 完全认可，进入共识
- **有保留同意** — 方向认可但有具体保留意见（必须写明保留什么）
- **反对** — 不认可（必须附一句话理由）

## 禁止行为

- 禁止引入 PRD 之外的新事实当作已确认依据（可标注"待查证"）
- 禁止人身评价（"这个想法很业余"❌ → "这个判断缺少证据"✅）
- 禁止循环争论同一个点超过一来回——第二次撞车直接标记"转仲裁"
